# One-to-Two-Minute Demo Script

Target duration: approximately 90 seconds.

## 0:00–0:10 — Introduction

“Hello, I’m Yateen Sakhare. This is WeatherScope, my full-stack AI Engineer
technical assessment for PM Accelerator. It uses React and TypeScript on the
frontend and FastAPI, SQLAlchemy, SQLite, and Open-Meteo on the backend.”

## 0:10–0:30 — Live weather

- Search for Philadelphia.
- Select the normalized result.
- Point out current temperature, feels-like temperature, humidity, wind,
  weather condition, and five-day forecast.
- Briefly show the map.

## 0:30–0:50 — Date range and persistence

- Select a short valid date range.
- Preview the weather.
- Add a note.
- Save the search.
- Show the new record in saved-search history.

## 0:50–1:10 — CRUD and export

- Open the saved record.
- Change the note or unit system and save.
- Download CSV or JSON.
- Mention that deletion cascade-removes associated daily rows.

## 1:10–1:25 — Code and architecture

- Show the repository briefly.
- Point to FastAPI routes, services, repositories, SQLAlchemy models, React
  components, and automated tests.
- Open Swagger at `/docs`.

## 1:25–1:30 — Closing

“The application includes real API integration, full CRUD, data exports,
error handling, tests, responsive design, and documentation. Thank you for
reviewing my submission.”

## Recording checklist

- Close unrelated tabs and notifications.
- Use readable browser and editor zoom.
- Seed one record before recording.
- Do not expose personal files, tokens, email, or browser bookmarks.
- Confirm microphone quality.
- Confirm the final video link is accessible without requesting permission.
