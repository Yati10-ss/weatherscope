# Screenshot Guide

Add these images before submission:

1. `dashboard-desktop.png`
   - approximately 1440 × 900
   - selected location, current weather, forecast, and map visible

2. `dashboard-tablet.png`
   - approximately 768 × 1024
   - demonstrate responsive card wrapping

3. `dashboard-mobile.png`
   - approximately 375 × 812
   - demonstrate stacked controls and readable forecast cards

4. `saved-searches.png`
   - show at least one persisted record and CRUD/export actions

5. `swagger-api.png`
   - show the FastAPI endpoint groups in Swagger UI

Before capturing screenshots:

- use realistic but non-sensitive sample data;
- hide browser bookmarks and personal tabs;
- remove debug messages;
- ensure no error banners are visible;
- use consistent browser zoom.
